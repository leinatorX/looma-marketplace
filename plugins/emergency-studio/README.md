# 应急科普内容工作室（emergency-studio）

面向应急、消防、危化和安全生产领域的内容创作插件，包含 **2 个技能**：

- `article-writer`：应急科普公众号文章与选题策划，从选题、调研、策划、成稿到发布前自检。
- `knowledge-graph`：应急安全知识图谱出图闭环，从立项、调研、分图方案、出图提示词、自检到发布文案。

两个技能可独立使用，也可串联：先出文章（`article-writer`），再为文章配知识图谱或封面（`knowledge-graph`）。

## Skills

| 目录 | 职责 | 典型触发 |
| --- | --- | --- |
| `article-writer` | 应急科普公众号文章与选题策划 | 写安全科普推文、标准解读、事故复盘 |
| `knowledge-graph` | 知识图谱出图 + 发布文案 | 做知识图谱、出图提示词、图文发布 |

## 使用建议

- 文章写作：先由技能输出策划方案，用户确认方向后再成稿。
- 知识图谱：默认优先前两图留人，图 1 制造 1 秒停顿，图 2 承接并给出继续翻页的理由。
- 出图：默认模型 `gpt-image-2`，默认画幅 3:4 竖版；封面按平台要求处理。
- 发布文案：自动落盘到项目主题目录 `YYYY-MM-DD-主题名/`。

## 边界

- 本插件输出方案、文章和提示词，默认不直接调用生成 API。
- 真正出图可衔接 `image-generator` 等执行类插件。
- 涉及法规、标准、事故、数据必须先核实来源，不凭记忆编写。

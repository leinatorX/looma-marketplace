Humanizer-zh 是一个用于去除文本中 AI 生成痕迹的中文 Skill，帮助你将 AI 生成的内容改写得更自然、更像人类书写。本仓库条目将其封装为 Looma 插件，遵循 **Codex 官方插件格式**，与 `image-generator`、`emergency-studio` 等其他插件采用一致的目录与清单结构。

## 版本同步说明

当前版本 `1.1.0` 对齐原作者 **2026-09-23** 修订。该次上游更新将原有的 24 类模式清单重构为 31 条检查点，并新增《编辑约束与优先级》《文体与作者声音》《工作流程》《输出与文件保护》《交付前核对》等章节，核心取向从"去 AI 味"转向"在不篡改原意的前提下编辑"。

上游 frontmatter 中的 `allowed-tools` 与 `metadata` 属于 Claude Code 专属字段，Looma / Codex 插件格式不识别，收录时已移除。其中"仅在用户要求时写回文件"的约束由正文《输出与文件保护》承载，语义未丢失。

## 适用场景

- 编辑和审阅 AI 生成的内容。
- 提升公众号、博客、专栏、newsletter、邮件的人性化程度。
- 学习识别 AI 写作的常见模式。
- 处理"中译中"修订，重点清理翻译腔、机械对照句、空泛大词、口号式收束。

## Skill

| 目录            | 职责                                                 |

| `humanizer-zh` | 识别并改写 31 类 AI 写作痕迹，保留事实与作者声音 |

加载后 Skill id 形如：`plugin:humanizer-zh:humanizer-zh`。

## 31 条检查点速览

- **A. 铺垫代替陈述（5）**：不是 X 而是 Y、单句收尾与戏剧性碎片、格言与伪深度、起跑式铺垫、与假想敌辩论。
- **B. 公式化节奏（6）**：强凑三段式、句式开头复读、破折号当万能连接、限定词堆叠、生造复合词与连接号、被动与缺主语。
- **C. 拔高与借权威（7）**：AI 高频词、意义拔高、模糊关联、句尾补充式拔高、宣传语、借权威、回避"是／有"。
- **D. 公式化排版（3）**：粗体当装饰、装饰性标题、引号与中文标点。
- **E. 聊天与草稿残留（4）**：客服腔、知识边界免责与猜测填充、首句复读标题、谈论上一稿。
- **F. 中文表达的补充检查（6）**：层叠的"的"、"进行＋动词"、被字句堆叠、四字词排比、"随着……的发展"式开头、套话收尾。

每条都配有「改写前 / 改写后 / 保留」三组示例，明确划定不应修改的边界。完整定义、适用条件和改写策略见 `skills/humanizer-zh/SKILL.md`。

## 边界

- 本 Skill **不调用任何外部网络或 API**，所有改写由宿主模型完成。
- 不修改用户文件，不在仓库中携带 API Key、Token 或用户私有数据。
- 不包含 `.mcp.json` 或 `hooks/`，因此不会扩大宿主能力边界。

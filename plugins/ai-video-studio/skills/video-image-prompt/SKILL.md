# 图片提示词工程师

## 目标

为 AI 视频所需的**每一类参考资产图**撰写可直接复制的图像提示词。默认中文交付，图像模型提示词按模型习惯可输出英文。默认图像模型 `GPT Image 2`，复杂多图/强文字可建议 `Nano Banana Pro`。

详细模板与官方写法见 `references/image-prompt-templates.md`。

## 触发场景

- 只需要一张或几张图（定妆照、产品图、封面、海报、示意图），不涉及完整资产规划时。
- 已有资产清单，需要把每一项转成具体图像提示词时。
- 用户明确要「写图 prompt / 出图提示词 / 图像模型提示词」时。

## 输入与前置

优先接收以下输入（信息不足可合理假设并注明）：

- 画面主体：人物/产品/场景/物件，稳定特征（脸、服装、材质、标识）。
- 用途：定妆照、三视图、道具图、场景图、风格帧、首尾帧、封面图。
- 风格：写实、电影感、广告摄影、产品摄影、赛博、复古胶片、动画等。
- 画幅：1:1 / 3:4 / 9:16 / 16:9。
- 目标图像模型：默认 `GPT Image 2`；复杂多图/强文字建议 `Nano Banana Pro`。
- 是否图生图：是否基于已有参考图修改（换装、去背景、补细节、统一多图）。

若用户已有完整资产规划（来自 `video-asset-art`），本技能只负责把每项转成提示词，不重复规划资产。

## 硬规则

1. 每张图对应**一条**可直接复制的提示词，标注用途、画幅、模型和参数建议。
2. 默认按给定模型写法输出；用户未指定模型时用 `GPT Image 2` 写法。
3. 角色一致性场景必须把「禁止变化项」写进提示词：脸、服装、比例、标识、品牌色、场景结构。
4. 涉及真实人物肖像、品牌标志、受版权保护角色时提示合规风险；不生成侵权、规避审核或违规内容提示词。
5. 不虚构官方能力；不确定的参数或能力标注需以官方文档为准。

## 默认输出

对每类资产（可复用以下结构）：

```text
## 资产名（用途 + 画幅 + 目标模型）

### 提示词
（可直接复制给图像模型）

### 参数建议
尺寸 / 质量 / 格式 / 是否需要多张候选

### 一致性约束
（禁止变化项）
```

## 与其它 Skill 的衔接

- 需要从剧本提炼完整资产清单 → `video-asset-art`（先定资产，再写提示词）。
- 需要写序列级视频提示词 → `video-prompt-engineer`。
- 真正出图可衔接 `image-generator` 等执行类插件。

## 边界

- 不直接调用图像 API，除非用户提供可用工具/接口。
- 默认只输出提示词与参数，不承诺生成效果；生成后效果请以实际出图为准。

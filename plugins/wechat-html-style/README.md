# 公众号 HTML 排版（wechat-html-style）

将公众号文章整理成统一风格的本地 HTML 排版页，便于预览和复制到微信公众平台编辑器。

包含 1 个技能：`html-layout`。

## Skills

| 目录 | 职责 | 典型触发 |
| --- | --- | --- |
| `html-layout` | 生成统一风格的公众号可复制 HTML | 排版公众号文章、复制到公众号、统一每期风格 |

## 使用建议

- 本技能负责排版而不是创作：正文内容先由 `article-writer` 或用户提供。
- 每期 HTML 放在独立文件夹 `YYYY-MM-DD-文章主题/` 下，图片放同级 `assets/`。
- 正文使用 `id="wechatArticle"` 容器 + 内联样式，保证复制到微信编辑器后保留主要效果。

## 边界

- 不依赖外部 CSS、CDN、字体或远程脚本。
- 不提交密钥、Token 或其他敏感信息。
